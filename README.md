# DELLA — Сервис подбора грузов для водителей-грузоперевозчиков (Казахстан)

Современный веб-сервис поиска и подбора попутных и генеральных грузов для грузоперевозчиков по Республике Казахстан.
Интерфейс сервиса выполнен строго на русском языке в лаконичном деловом стиле в соответствии с дизайн-системой DELLA.

---

## 🚀 Основные особенности и преимущества

1. **Модуль автоматических голосовых звонков водителям (Voice Bot):**
   - **Мгновенная инициация звонка:** от момента создания груза до вызова телефонии проходит **< 3 секунд** (в тестах ~300-500 мс).
   - **Интеллектуальный голосовой робот:** озвучивает водителю маршрут, тоннаж, ставку в тенге и дату погрузки.
   - **Интерактивное DTMF-управление:**
     - **Клавиша 1 («Взять груз»):** груз переходит в статус *«В работе»*, закрепляется за водителем, диспетчер видит подтверждение.
     - **Клавиша 2 («Отказаться»):** 2-минутная блокировка снимается, система сразу вызывает следующего подходящего водителя.
     - **Клавиша 9 («Повторить»):** робот повторяет параметры груза.
   - **Учёт согласий и статуса водителя:** робот звонит **только** если есть галочка `call_consent` (согласие) и статус водителя — *«Свободен»* (статус меняется водителем в личном кабинете на *«В рейсе»* или *«Отдыхает»*).
   - **Защита от спама и ночной режим:** не более 3 звонков одному водителю в час; авто-пауза в ночные часы (23:00–06:00).
   - **Резервные каналы (SMS / Telegram) и эскалация:** при отсутствии ответа отправляется ссылка на груз, а через 10 минут диспетчер получает предупреждение о необходимости ручного звонка.
   - **Панель мониторинга диспетчера («Автозвонки»):** живая статистика звонков, SLA задержки, глобальный рубильник вкл/выкл и кнопка **«Тестовый звонок»**.

2. **Честная ставка (Honest Rate):**
   - Ставка в карточке груза утверждается диспетчером и получает статус **«Подтверждена»**.
   - Водитель не сталкивается с ситуацией, когда по приезде на погрузку цена оказывается ниже обещанной.
   - Любое изменение ставки диспетчером требует обязательного указания причины, сохраняется в открытую историю аудита (кто, когда, было/стало) и отправляет мгновенное уведомление водителю.
3. **Интеллектуальный подбор под габариты машины:**
   - Алгоритм автоматически проверяет: `вес груза <= грузоподъёмность`, `тип кузова совпадает`, `город погрузки совпадает с городом дислокации авто`, `статус груза = Открыт`.
   - **Сортировка:** сначала груз, у которого вес ближе всего к грузоподъёмности (минимальный недогруз, например машина 15 т и груз 14 т — «Лучшее совпадение»), затем по ближайшей дате погрузки.
   - Водителю на первом грузе сразу доступна кнопка **«Беру груз»**.
4. **Бесплатно для водителей:**
   - Никаких платных подписок, скрытых комиссий или платного «открытия номеров телефонов».
5. **Закрытая безопасная регистрация + Единый реестр доступов водителей:**
   - Самостоятельной регистрации нет. Диспетчер сам создаёт учётную запись водителя и вносит параметры его автотранспорта.
   - **Генератор логина и пароля в 1 клик:** создание понятного красивого логина (`driver_erbol_12`) и надёжного читаемого пароля (`Della7491`).
   - **Единый реестр доступов диспетчера:** все выданные логины и пароли сохраняются в базе и доступны во вкладке «Реестр доступов (Логины и пароли)».
   - **Быстрая отправка водителю:** кнопка «Скопировать SMS / WhatsApp» формирует готовое персональное сообщение со ссылкой на сайт и данными входа.
   - **Экспорт в Excel / CSV:** скачивание полной базы доступов в 1 клик с кодировкой UTF-8 BOM.
   - Защита от брутфорса (rate-limiting), пароли захешированы в `bcrypt`, действия диспетчеров логируются в журнал аудита.
6. **Жалобы и рейтинг 1–5 звёзд:**
   - Возможность оставить отзыв и оценку после завершённого рейса.
   - Кнопка «Пожаловаться» на каждом грузе и в профиле водителя.

## 🛠 Технологический стек

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS (кастомная палитра `#F3F5F8`, `#0F172A`, `#1D4ED8`, `#166534`, скругления 16px, кнопки высотой от 48px).
- **Backend:** Node.js, TypeScript, Express, Prisma ORM, JWT, bcryptjs, Zod (все ошибки валидации на русском языке).
- **База данных:** PostgreSQL 16 (также поддерживается zero-setup SQLite режим `file:./dev.db` для мгновенного запуска без установки внешних СУБД).

## ⚡ Инструкция по запуску

### Вариант 1: Быстрый запуск (рекомендуется)

База данных уже инициализирована и наполнена тестовыми данными (1 диспетчер, 3 водителя, 10 грузов по городам РК, отзывы, жалобы, журнал аудита).

#### 1. Запуск Backend:
```bash
cd backend
npm install
npm run dev
```
*Сервер запустится на `http://localhost:5000` (API: `http://localhost:5000/api`).*

#### 2. Запуск Frontend:
```bash
cd frontend
npm install
npm run dev
```
*Приложение откроется на `http://localhost:3000`.*

---

### Вариант 2: Запуск с PostgreSQL через Docker

Если вы хотите использовать PostgreSQL:

1. Запустите контейнер PostgreSQL:
```bash
docker compose up -d
```
2. В папке `backend` переключите схему на PostgreSQL:
```bash
cd backend
npm run db:use-postgres
npm run db:push
npm run db:seed
npm run dev
```

*(Для возврата к SQLite достаточно выполнить `npm run db:use-sqlite && npm run db:push && npm run db:seed`).*

## 📋 Сценарии для проверки функционала

### Сценарий 1: Проверка умного подбора для водителя (Ербол, Шымкент)
1. На странице входа нажмите кнопку **«Водитель (Шымкент)»** и войдите в систему.
2. Откроется кабинет:
   - Слева карточка **«Моя машина»**: город *Шымкент*, кузов *Тент*, грузоподъёмность *15 т*.
   - Справа список **«Подходящие грузы»**:
     - **Первая карточка** с яркой пометкой **«Лучшее совпадение»** — это рейс **#101 Шымкент → Астана (14 т)**, так как разница между машиной 15 т и грузом 14 т минимальна (запас всего 1 т!).
     - На первой карточке отображается зелёная кнопка **«Беру груз»**.
     - Груз #109 (Шымкент → Тараз, 16 т) отфильтрован, так как превышает грузоподъёмность 15 т.
3. Нажмите **«Беру груз»** — заявка мгновенно фиксируется и отправляется диспетчеру.
4. В карточке «Моя машина» смените город на **Алматы** и нажмите «Найти груз» — список мгновенно перестроится под грузы из Алматы.

### Сценарий 2: Проверка Честной Ставки (Диспетчер)
1. Выйдите из профиля водителя и войдите как **«Диспетчер»** (`dispatcher` / `password123`).
2. В разделе **«Грузы»** найдите рейс #101 или любой другой груз.
3. Нажмите **«Изменить ставку»**:
   - Введите новую сумму (например, 700 000 ₸ вместо 650 000 ₸).
   - Укажите причину: *«Заказчик согласовал надбавку за срочность подачи»*.
   - Нажмите **«Подтвердить ставку»**.
4. В карточке груза нажмите **«История ставки»** — отобразится прозрачная история с датой, автором и причиной изменения.
5. Водитель получит уведомление в личном кабинете.

### Сценарий 3: Подбор водителей и фиксация звонка
1. В панели диспетчера перейдите на вкладку **«Подбор»**.
2. Выберите груз #101 (Шымкент → Астана, 14 т, Тент).
3. Алгоритм покажет водителя **Ербол Сериков** на 1-м месте с пометкой **«Лучшее совпадение»** (запас по весу 1 т).
4. Нажмите **«Позвонить»**:
   - Откроется модальное окно с кликабельной ссылкой `tel:+77771234567`.
   - Зафиксируйте результат звонка: выберите **«Согласен»** (или «Отказался», «Не ответил») и введите комментарий.
   - При выборе «Согласен» груз автоматически переходит в статус «В работе», а водитель назначается исполнителем рейса.

### Сценарий 4: Создание нового водителя диспетчером
1. Перейдите во вкладку **«Водители»** и нажмите **«Создать водителя»**.
2. Введите ФИО, телефон, желаемый логин, пароль и параметры машины (город, кузов, тоннаж).
3. После сохранения появится окно с учетными данными для передачи водителю. Пароль сразу хешируется в bcrypt.
4. Также доступны кнопки **«Сбросить пароль»** (генерирует новый временный пароль) и **«Блокировать»**.

### Сценарий 5: Жалобы и журнал аудита
1. Вкладка **«Жалобы»**: фильтрация по статусам (*Новая*, *В работе*, *Закрыта*), возможность назначить резолюцию.
2. Вкладка **«Журнал действий»**: хронологический лог всех операций (создание водителей, звонки, изменение честных ставок, сбросы паролей, входы в систему).

### Сценарий 6: Мониторинг автозвонков и проведение тестового звонка
1. Войдите как диспетчер и перейдите во вкладку **«Автозвонки»** (`/admin/calls`).
2. В верхней панели видна общая сводка:
   - Общее количество звонков, процент успешности (Success Rate).
   - Индикатор средней задержки (SLA) — зафиксировано время между появлением груза и звонком (< 3 сек).
   - Глобальный рубильник работы системы автозвонков.
3. Нажмите кнопку **«Тестовый звонок»**:
   - Выберите водителя (например, Ербол Сериков) и груз (например, #101).
   - Выберите провайдера телефонии (`mock`, `twilio`, `zadarma`) или оставьте симулятор.
   - Нажмите **«Инициировать звонок»** — система произведёт вызов и покажет симуляцию голосового сообщения робота и кнопок DTMF.
   - Нажмите клавишу **1 (Взять груз)** прямо в модальном окне: статус груза обновится на «В работе», а в таблице звонков появится новая запись с точным таймингом отклика.

### Сценарий 7: Автоматический звонок при создании нового груза
1. В панели диспетчера во вкладке **«Грузы»** нажмите **«Добавить груз»**.
2. Введите параметры: Шымкент → Алматы, 14 тонн, Тент, ставка 500 000 ₸.
3. Нажмите **«Сохранить груз»**.
4. В этот же момент бэкенд за миллисекунды:
   - Сохраняет груз в БД;
   - Публикует событие в очередь автозвонков;
   - Находит подходящего водителя Ербола Серикова (Шымкент, Тент, 15 т, свободен, есть согласие);
   - Резервирует груз на 2 минуты;
   - Инициирует звонок робота (задержка SLA < 3 секунд);
   - Запись звонка моментально отображается во вкладке **«Автозвонки»**.

## ⚙️ Настройка провайдеров телефонии (Twilio / Zadarma)

По умолчанию в режиме разработки и демонстрации используется встроенный отказоустойчивый симулятор (`mock`), не требующий подключения внешних API.

Для подключения реальной телефонии укажите ключи в файле `backend/.env`:

```env
# Основной и резервный провайдеры (mock | twilio | zadarma)
TELEPHONY_PRIMARY_PROVIDER="twilio"
TELEPHONY_FALLBACK_PROVIDER="zadarma"

# Twilio Programmable Voice
TWILIO_ACCOUNT_SID="ACXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"
TWILIO_AUTH_TOKEN="your_twilio_auth_token"
TWILIO_PHONE_NUMBER="+77000000000"

# Zadarma API
ZADARMA_KEY="your_zadarma_api_key"
ZADARMA_SECRET="your_zadarma_api_secret"

# Публичный URL для вебхуков провайдера (например, через ngrok или домен)
BASE_WEBHOOK_URL="https://your-domain.kz"
```
